# Changelog

## 0.1.0

- interactive dashboard: status, ahead/behind, conflicts, stashes, last commit age and stack per repo
- scrolling list, filter (`/`, with `:dirty` `:unpushed` `:behind`), sort, and a detail panel
- fetch all, fast-forward pull (one or all), open in editor, open remote in browser
- `--plain`, `--json`, `--dirty`, `--unpushed`, `--behind`, `--fetch` and `--check` for scripts
- `--depth` to find repos grouped in folders
